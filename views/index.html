TaskManager

Aplicación web para optimizar la administración, seguimiento y asignación de tareas dentro de equipos de trabajo colaborativos, permitiendo que múltiples usuarios interactúen simultáneamente.

Equipo de desarrollo

Administrador Ramas y aprobaciones
Desarrollador 1 Módulo de interfaz
Desarrollador 2 Módulo JavaScript
Desarrollador 3 Documentación

Objetivo del proyecto

El objetivo principal de TaskManager es administrar de manera eficiente las tareas y actividades de un equipo de trabajo, garantizando la organización de flujos, el control de tiempos y la correcta asignación de responsabilidades bajo un entorno controlado.

Alcance del proyecto

La aplicación web contempla la implementación y liberación de los siguientes módulos funcionales centrales en su primera versión:

  • Autenticación (Login): control de acceso seguro para los integrantes del equipo.
  • Interfaz de usuario: panel visual interactivo para la gestión de actividades.
  • Lógica (JavaScript): comportamiento dinámico para crear, actualizar y borrar tareas en tiempo real.
